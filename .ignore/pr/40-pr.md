# 概要

社内DocumentViewからIDPを再実行し、項目化結果と確信度を表示できるようにする。バックエンドは既存のIDP実行API（POST/GET /api/documents/{document_id}/idp-runs）を流用し、Viewer側のみ追加。

## 関連Issue

Closes #39

## 変更内容

- `IdpRunPanel.vue` 新規作成
  - 「IDP実行」ボタン（実行中スピナー+多重実行防止disabled）
  - 選択実行の項目化結果（normalized_fields）+確信度（%表示）の項目別テーブル表示。失敗実行はerror_info表示
  - 実行履歴一覧（実行日時降順・実行区分・ステータス）。行選択で当該回の結果へ切替
  - マウント時・文書ID変更時に履歴自動取得し最新実行を初期選択
- `DocumentView.vue`: 文書表示成功時にパネル組込（表示確定済文書IDを引き渡し。入力途中の値と区別）
- PublicView変更なし=再実行操作・結果表示は社内のみ
- API変更なし・結果矩形オーバーレイなし（実行応答に座標情報なし）
