# 概要

ログイン後の画面でボタンが素のテキスト表示になり、文書ID入力欄（v-text-field）が表示されない問題を修正する。

## 関連Issue

Closes #23

## 変更内容

- 原因: `createVuetify()` に `components` / `directives` を渡しておらず、`<v-btn>` `<v-text-field>` 等が未知のカスタム要素として素通し描画されていた（スロットテキストを持つボタンは文字だけ見え、持たないテキストフィールドは不可視）。Viewerスケルトン導入時からの潜在バグで、入力欄の追加により顕在化
- Vuetify設定を `src/plugins/vuetify.ts`（`createAppVuetify()`）へ切り出し、`vuetify/components` / `vuetify/directives` を登録
- `main.ts` とテストで同一設定を使用（設定差異による見逃しを防止）
- 回帰テスト2件追加（v-text-field が input、v-btn が button として描画されること）
