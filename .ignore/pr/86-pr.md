# 概要

#81 の文書種別テナント別設定値化でviewer側に残ったハードコード（種別表示名・閲覧URLタブの表示制御）を、`document_type_configs` の設定値参照へ修正する。

## 関連Issue

Closes #85

## 変更内容

- `AppHeader.vue`: 種別チップの表示名ハードコード（`typeLabels`）を削除し、設定の `display_name` を表示（設定未取得時は種別コードをフォールバック表示）
- `WorkPanel.vue`: 閲覧URLタブの表示制御を `documentType === 'quote'` 判定から `shareable` prop に変更（`documentType` prop は用途消滅のため削除）
- `DocumentView.vue`: 文書取得と並行で `GET /api/config/document-types` を取得し、`display_name` / `shareable` をストアへ反映。取得失敗・設定なしは表示名フォールバック・共有不可の安全側（発行可否はサーバー側でも強制済）
- `stores/document.ts`: `documentTypeDisplayName` / `documentTypeShareable` を追加
- テスト追加・更新: 設定値表示、フォールバック（取得失敗・未登録種別）、shareableゲート

API変更なし。
