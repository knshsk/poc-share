# 概要

Viewer UIプロダクトレベル化（#74）のビジュアル基盤。Fluent Azureカスタムテーマ・IBM Plexフォント・Phosphor Iconsを導入し、アプリシェル（アプリバー・ログイン画面）を刷新する。

## 関連Issue

Closes #75

## 変更内容

- Vuetifyカスタムテーマ `factone` を定義（`plugins/vuetify.ts` がカラートークンの唯一の定義箇所。コンポーネント側hex直書き禁止）
- Vuetify内部アイコンエイリアスをPhosphor Iconsへ差し替え（mdi依存なし）
- IBM Plex Sans JP / IBM Plex Mono を @fontsource でセルフホスト導入
- `AppHeader.vue` 新設（ロゴ・ユーザメニュー・ログアウト）
- `App.vue` をシェル構成に刷新。中央カードのログイン画面。デバッグ要素（`/api/me` 表示・API呼出ボタン）を除去
- テスト: テーマトークン・アイコン描画・AppHeader・デバッグ要素非表示の検証を追加（31件通過）
