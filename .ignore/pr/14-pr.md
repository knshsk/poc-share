# 概要

Pydanticモデルを単一情報源とするAPI契約の型共有パイプライン（OpenAPIエクスポート → TypeScript型生成 → 生成物コミット＋差分チェック）を構築する。

## 関連Issue

Closes #13

## 変更内容

- `api/scripts/export_openapi.py` — `create_app().openapi()` をJSON出力
- `docs/api/openapi.json` — エクスポート固定物（外部向け契約レビュー・共有用の正）
- `viewer/src/api/schema.d.ts` — openapi-typescript による生成TS型（コミット対象）
- viewer へ `openapi-typescript`（dev）・`openapi-fetch` 追加、`npm run generate:api` で一括生成
- pre-commit へ「API契約生成物の差分チェック」フック追加（再生成→差分あれば失敗）
- 生成物は eslint・prettier の対象外（整形が生成差分チェックと衝突するため）
- 生成手順を `docs/develop-guide/api.md` へ追記
