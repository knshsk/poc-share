# 概要

案件型見積PDF向けの閲覧URLを発行・失効でき、顧客はURLのみ（認証なし）で閲覧できる。決定済みの「不透明ランダムトークン+DB管理」方式の実装。

## 変更内容

データモデル（`docs/data-model/view-tokens.md`）:

- `view_tokens` — id(UUID管理ID) / token_hash(SHA-256・UNIQUE。**平文は保存しない**) / document_id(FK) / issued_at / expires_at(必須・既定90日=設定値の仮置き) / revoked
- `view_access_failures` — 失敗試行記録（トークン先頭8文字のみ・IP・日時）

API:

- `POST /api/documents/{document_id}/view-urls` — 発行（JWT必須）。トークン=256bit URL-safe乱数、応答で一度だけ平文返却。発行可否は `DocumentType.customer_shareable` 属性で判定（見積のみ。注文書は403=VWR-04）→ **ADR-0002**
- `GET /api/documents/{document_id}/view-urls` — 発行済み一覧（平文なし）
- `POST /api/view-urls/{id}/revoke` — 即時失効（行更新のみ）
- `GET /view/{token}/pages` / `/pages/{page}/image` / `/pdf` — 無認証閲覧。検証=ハッシュ照合+未失効+期限内。無効は一律404（存在推測防止）+失敗記録。IP単位の固定窓レート制限（60秒10失敗で429・インメモリ）

Viewer:

- `/view/{token}` パスで無認証閲覧画面（PublicView。ページ表示+DL、ログインUI非表示）
- `PageSvg` に token モード追加、Vite devプロキシへ `/view/{token}/pages|pdf` 経路追加（`/view/{token}` 自体はSPAページ）

テスト12件（セキュリティ検証対象=厚くする領域）: 発行のquote限定403・平文非保存・失効の即時反映・不存在/期限切れ404の一律性・失敗記録（断片のみ）・レート制限429・未認証401
