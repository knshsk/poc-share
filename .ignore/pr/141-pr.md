# 概要

`docs/` に上位層（全体像・モジュール構成）を追加する作業の 1 本目。読み順の案内、L1 全体像、Azure 構成の設計文書を作成し、既存 Markdown の文体を常体に統一する。

## 変更内容

- `docs/README.md` を L0（PoC 要件）→ L1（全体像）→ L2（モジュール構成）→ L3（詳細仕様）の読み順案内に書き換え
- `docs/architecture/overview.md`（L1）を新設: システム文脈図・コンポーネント構成図・主要ユースケースのシーケンス図 4 本・データの流れと保存先
- `docs/azure/README.md` を実体化: トポロジ図・Bicep モジュール別の設計（目的 / 主要設定 / ID と権限 / PoC 上の簡略化）・通信と認証経路
- `docs/architecture/README.md` を L1/L2 の一覧と記述方針に書き換え（L2 4 文書は 2 本目で追加）
- 既存 Markdown（`docs/` 配下・`api/README.md`・`viewer/README.md`・`keycloak/README.md`）の丁寧語を常体に統一（内容変更なし、行数 1:1）
- ルート `README.md` から `docs/README.md` へリンク

L1/L2 にはテナント固有の外部システム名を書かず、外部は役割名（テナント利用者・外部連携システム・閲覧者）で表す。
