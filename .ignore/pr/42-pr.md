# 概要

Azureデプロイ環境でIDP実行APIが502（`DiError: Document Intelligence endpoint is not configured`）になる問題を修正。Container Appの環境変数に `FACTONE_DI_ENDPOINT` が設定されていなかったため、Document Intelligenceのエンドポイントをbicepで注入する。

## 関連Issue

Closes #41

## 変更内容

- `bicep/modules/api-app.bicep`: param `diEndpoint` を追加し、環境変数 `FACTONE_DI_ENDPOINT` として設定
- `bicep/main.bicep`: `apiApp` モジュール呼出に `diEndpoint: documentIntelligence.outputs.endpoint` を追加
- APIキーは設定しない（`api/app/di.py` がキー未設定時にManaged ID認証へフォールバック。Cognitive Services Userロールは付与済）
