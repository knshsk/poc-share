# 概要

書類種別設定のシードを `order_project` / `order_route` / `quote` の3種別から `purchase_order`（注文書）/ `quotation`（見積書）の2種別に変更する。注文書はIDP実行後に案件型・ルート型へ分岐するため、実行前の種別で分けない。

## 関連Issue

Closes #105

## 変更内容

- 新規マイグレーション `b7e3d2a9c1f5` 追加
  - `documents.document_type` を `quote→quotation`、`order_project`/`order_route→purchase_order` に更新
  - `default` テナントの旧3設定を削除し新2設定を投入
  - downgrade は逆変換（`purchase_order→order_project`。案件/ルートの区別は復元不可）
- 新シードのフィールド（Query FieldsキーはDIドキュメントに倣いPascalCase）
  - `quotation`（shareable=true）: `SenderCompanyName`, `ReceiverCompanyName`(visible=false), `OrderDate`(date), `TotalAmount`(number), `DeliveryDate`(date), `DeliveryLocation`, `CustomerContactPersonName`, `QuotationId`
  - `purchase_order`（shareable=false）: 上記＋`PurchaseOrderId`
- テストfixture（conftest `DEFAULT_CONFIGS`）を新シードと同内容化、API/viewerテストの種別コード・フィールドキー固定値を追随
- `docs/data-model/document-type-configs.md` のシード表を更新
