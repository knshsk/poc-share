# 概要

`scripts/build-images.sh` が Viewer の `VITE_OIDC_AUTHORITY` に `factone-poc-keycloak` を直書きしていたため、`environmentName` を `poc` 以外にすると誤った authority が焼き込まれていた。`bicep/main.bicepparam` の `environmentName` を読み、`main.bicep` と同じ規則 `factone-<environmentName>-keycloak.<既定ドメイン>` でホスト名を組み立てる。

## 関連Issue

Closes #143

## 変更内容

- `scripts/build-images.sh`: `main.bicepparam` から `environmentName` を sed で抽出（未定義時は `poc`）し、ホスト名に展開
- `docs/azure/README.md`: 「トポロジ」節の直書きに関する記述を現状に合わせて更新

`VITE_OIDC_CLIENT_ID` は引き続き渡さない。Viewer の既定値 `factone-viewer` が realm のクライアント ID と一致しており、変える予定がないため（変えるときは同スクリプトに `--build-arg` を足す）。

## 動作確認方法

1. `bicep/main.bicepparam` の `environmentName` を一時的に `dev` にする
2. `./scripts/build-images.sh` を実行し、`Viewer OIDC authority: https://factone-dev-keycloak.<既定ドメイン>/realms/factone` と出ることを確認する（実ビルドまで進めなくてよい）
3. 抽出ロジック単体: `echo "param environmentName = 'dev'" | sed -n "s/^param environmentName = '\([^']*\)'.*/\1/p"` が `dev` を出す
