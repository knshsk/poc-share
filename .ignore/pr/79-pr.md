# 概要

Viewer UIプロダクトレベル化（#74）の主軸シナリオ（原本照合）向けレイアウト実装。DocumentViewを左（ページ表示+ナビ/ズーム）右（作業パネル）の2ペイン構成に刷新する。

## 関連Issue

Closes #76

## 変更内容

- `DocumentCanvas.vue` 新設: ページ連続縦スクロール＋ツールバー（前/次ページ・ページ表示・ズーム±25%（50〜200%）・幅合わせ・原本DL）。ズームはCSS width制御でPageSvgのviewBox（DI座標系）は不変
- `stores/document.ts` 新設: 文書コンテキスト（ID・種別）をヘッダと画面で共有
- `DocumentView.vue` を2ペイン化。幅960px未満は縦積みフォールバック。empty state（文書ID未指定・入力欄付き）／エラーstate（再試行）／スケルトンの状態設計
- `AppHeader.vue` に文書IDバッジ（クリックで再入力メニュー）＋種別チップ（見積/注文書（案件）/注文書（ルート））を追加
- `PageSvg.vue`: 画像取得中のパルス表示、hex直書き色をテーマトークン参照へ置換（viewBox・座標系は不変）
- テスト: DocumentCanvas（ナビ・ズーム・クランプ・DL emit）、documentストア、DocumentViewの状態3種、ヘッダ文書コンテキストを追加（42件通過）
