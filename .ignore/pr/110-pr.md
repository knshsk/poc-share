# 概要

FactONE全体設計の更新に追随し、`docs/business` 配下の業務ドキュメントを現行設計へ揃える。ドキュメントのみの変更で、アプリの動作・仕様に影響しない。

## 関連Issue

Closes #109

## 変更内容

- `operation-flow.md`: レーン定義を箇条書き形式に変更。K1〜K5・R1・F1〜F4 のシーケンス図を工程表へ置換。K③-2 通信手段を `URLパラメータ指定` に確定、K②-9 のWBS記載を削除
- `data-model.md`: FactONE全体の論理モデル（モデル一覧・エンティティ項目一覧・リレーション一覧）を新規記載。元資料で廃棄扱いのエンティティとER図を除去。「※付きは正本が外部システム・本書未定義」「番号は元資料準拠、欠番は廃棄」を明記
- `out-of-scope.md`: 全項目の構成統一と読み方の追記。OUT-21・OUT-22 追加、OUT-19 をモデル対象外表記に修正
- `entity.md`: 削除（`data-model.md` へ統合）
- `README.md`: ドキュメント一覧・記述方針を更新（工程表形式、業務側論理モデルと `../data-model/` 物理モデルの役割分担）
