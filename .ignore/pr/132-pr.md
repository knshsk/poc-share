# 概要

DI解析が `FACTONE_DI_TIMEOUT_SECONDS` 内に完了しない場合、500 `internal-error` ではなく 502 `document-analysis-failed` を返し、失敗実行を `idp_runs` に記録する。

## 関連Issue

Closes #119

## 変更内容

- `AzureDocumentAnalyzer.analyze`: `poller.result(timeout)` → `poller.wait(timeout)` + `poller.done()` 判定。未完了なら `DiError("Document Intelligence request timed out")` を送出（azure-core の `result(timeout)` はタイムアウト時に例外を出さず未完了応答を返すため）
- `tests/test_di.py`: フェイクpollerを差し込んだ `AzureDocumentAnalyzer.analyze` 単体テスト追加（タイムアウト / AzureError変換 / 正常組立）
- `docs/data-model/idp-runs.md`: タイムアウト超過をDI失敗として扱う旨を追記

## 動作確認方法

1. DI接続設定済み環境で `FACTONE_DI_TIMEOUT_SECONDS=1` にする
2. 文書登録後 `POST /api/v1/documents/{document_id}/idp-runs`
3. 502 `document-analysis-failed` が返り、`GET .../idp-runs` に `status=failed`・`error_info="Document Intelligence request timed out"` の実行が追記される
