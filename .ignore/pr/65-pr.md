# 概要

Power Automateの日次バッチが閲覧ログを差分取得できる横断フィードを追加する（業務フロー K3-9 / 要件 VW-04）。取得方式の決定はADR-0013として記録。

## 関連Issue

Closes #63

## 変更内容

- `GET /api/view-events?since=<日時>` を追加（JWT必須）
  - `since` は境界包含（`occurred_at >= since`）。境界上の重複はDD登録の冪等キー（文書ID＋発生日時）で連携側が排除する前提とし、取りこぼしゼロを優先
  - 応答は `occurred_at` 昇順（同時刻は `id` 順）。`document_id` を含む公開項目のみで、`view_token_id` は非公開
  - `since` 省略時は全件。不正な日時は422
  - テナント絞込（`documents.tenant_id`）あり
- ADR-0013 起票（横断フィード方式の決定・代替案・トレードオフ）
- `docs/data-model/view-events.md` の外部連携IF-04記載を横断フィードへ更新（文書ID単位IFは個別照会用として存続を明記）
- OpenAPIエクスポート・TS型を再生成
- テスト6件追加（横断取得・since境界包含・応答形状・認証必須・空リスト・不正since 422）

## 動作確認方法

1. ローカルスタック起動後、見積文書を登録し閲覧URLを発行
2. `/view/{token}/pages`・`/view/{token}/pdf` へアクセスしイベントを発生させる
3. JWT付きで `GET /api/view-events` → 全イベントが `document_id` 付き昇順で返ること
4. 応答中の `occurred_at` を `since` に指定 → 当該イベント以降のみ返ること（境界包含）
5. 未認証で 401、`since=not-a-date` で 422
