# 概要

文書種別設定の `fields` 要素に `visible`（Viewer表示可否、省略時 true）を追加する。Query Fieldsの精度向上のため対で指定するが表示不要な項目（例: 受領注文書の自社名）を、エンドユーザー向けの読み取り結果から除外できるようにする。

## 関連Issue

Closes #91

## 変更内容

- API: `FieldDefPayload` に `visible: bool = True` を追加。既存JSONB行は未指定 = true 扱い（データ移行なし）。抽出・保存・idp-runs応答は非表示項目も従来どおり保持
- Viewer: `DocumentView` が取得済み種別設定から `visible=false` のキーを `hiddenFieldKeys` としてストアへ保持し `WorkPanel` へ渡す。`WorkPanel` は読み取り結果の表示から除外。設定取得失敗・設定なしは全項目表示
- 判定は表示時に現在設定を参照（実行時スナップショットではない）。設定変更は過去実行分の表示にも反映
- `docs/api/openapi.json`・`viewer/src/api/schema.d.ts` 再生成、`docs/data-model/document-type-configs.md` 更新
- ponytail-review（過剰設計レビュー）指摘3件を適用済み

## 動作確認方法

1. `PUT /api/config/document-types/{type_code}` で任意の fields 要素に `"visible": false` を付与する
2. Viewerで該当種別の文書を開き、読み取り結果タブに当該項目が表示されないことを確認する
3. `GET /api/documents/{document_id}/idp-runs` の応答には当該項目が含まれたままであることを確認する
