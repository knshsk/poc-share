# 概要

認証あり API を `/api/v1/**` に移し、バージョニング方針（URL パス・メジャーのみ・破壊的変更時限定）を ADR-0017 と API 設計ドキュメントに固定する。

## 関連Issue

Closes #101

## 変更内容

- `/api/**` 15 ルートを `/api/v1/**` に変更。`/view/{token}/**` と `/health` は無版のまま
- OpenAPI の全パスが `/api/v1/`・`/view/`・`/health` のいずれかで始まることを検証するテストを追加
- Viewer の呼出パスを更新し、`openapi.json` と `schema.d.ts` を再生成
- ADR-0017 起票、`docs/api/README.md` にバージョニング節を追加、関連ドキュメントのパス表記を更新
- 旧 `/api/**` の互換ルート・リダイレクトは作らない（外部利用者なし）
