## 備考

- mypy は公式mirrorでなく local hook（プロジェクト依存の型情報参照のため）
- eslint の TypeScript設定ファイル読込に `jiti` が必要なため dev依存へ追加
- `_env_file` はpydantic-settingsの実行時専用引数で型定義に現れないため、テスト2箇所に `type: ignore[call-arg]` を付与
- テストは pre-commit に含めない（コミット毎実行は過剰。`uv run pytest` / `npm run test` を従来どおり使用）
- CI・TS型生成差分チェック・シークレット検出フックはスコープ外
