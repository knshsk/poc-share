# 概要

書類種別設定の `key` / `type_code` バリデーションで大文字を許可する。Document Intelligence のドキュメントに倣い PascalCase のキーを登録可能にする。

## 関連Issue

Closes #103

## 変更内容

- `_CODE_PATTERN` を `^[a-z0-9_]{1,50}$` → `^[A-Za-z0-9_]{1,50}$` に変更（`key` と `type_code` で共有）
- PascalCase の `key` / `type_code` で 201 になるテストを追加
- `docs/data-model/document-type-configs.md` の正規表現表記を更新
- `docs/api/openapi.json` を再生成

## 動作確認方法

`POST /api/v1/config/document-types` に `type_code: "PurchaseOrder"`, `fields[0].key: "InvoiceNo"` で 201。`invoice-no` のようなハイフン入りは引き続き 422。

## 備考

`key` の一意性判定は大文字小文字を区別する（`InvoiceNo` と `invoiceno` は別キー）。DI Query Fields も大文字小文字区別のため整合。
