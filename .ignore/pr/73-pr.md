# 概要

DI読み取りで返却される値を拡充。Query Fields（書類ヘッダ項目）に加え、DIが認識したテーブル領域を明細（仮）として保持・返却する。

## 関連Issue

Closes #72

## 変更内容

- `api/app/services/di.py`: analyze返却を `AnalysisResult`（fields+tables）に拡張。`extract_tables` でprebuilt-layout応答のtablesを `DiTable`（行列数・セル内容・kind・ページ番号・polygon座標）へ変換。複数テーブル認識時は全件保持
- `api/app/services/idp_extraction.py`: `tables_to_json` 追加。テーブルは正規化・意味付けせず素通し（明細領域の特定・SAP入力項目との対応付けはSaaS責務外）
- `api/app/models.py` + マイグレーション `e7b2c4a1f9d3`: `idp_runs.tables`（JSONB・NULL可）追加
- `api/app/routers/idp_runs.py`: 成功時にtables保存、POST/GET応答に `tables` 追加（失敗時NULL・テーブル未検出は空配列）
- TS型（`viewer/src/api/schema.d.ts`）・OpenAPIエクスポート再生成
- `docs/data-model/idp-runs.md` にtables列と構造を追記
