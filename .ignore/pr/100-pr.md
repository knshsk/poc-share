# 概要

Power Automate経由の定型登録フローに乗らないPDFを、Viewer画面から直接登録できるようにする。

## 関連Issue

Closes #99

## 変更内容

- `DocumentView` の empty state（文書ID未指定）を選択ダイアログ化。「文書IDを指定して閲覧」/「新規登録」を選択
- `DocumentRegisterForm` 新規追加: 文書ID（ユーザ入力）・書類種別（`GET /api/config/document-types` の `display_name` から選択）・PDFを既存の `POST /api/documents` へmultipart送信。成功（201/200）時にその文書IDを表示対象にする
- エラー表示: 409 →「文書IDは別の内容で登録済み」、その他は Problem Details の `detail`。フォーム維持で再試行可
- API変更なし。誤登録時のフォロー手段（取消・差替）はPoC対象外
- docs: `requirements/viewer.md`（VW-08追加・境界の文書ID記述更新）、`viewer/display.md`（開始画面・POSTエンドポイント追記）、`viewer/README.md`

## 動作確認方法

1. `document_id` パラメータなしでViewerを開きログイン
2. ダイアログで「新規登録」を選択し、文書ID・書類種別・PDFを指定して「登録」
3. 登録した文書が表示されることを確認
4. 同じ文書IDで別PDFを登録 → 409エラー表示を確認
5. 「戻る」→「文書IDを指定して閲覧」で従来どおり表示できることを確認
