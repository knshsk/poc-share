# 概要

#117 / #118 で追加した読取結果の修正 UI と相互ハイライトに、スクリーンリーダー・キーボード利用者向けの基礎的なアクセシビリティを追加する。

## 関連Issue

Closes #127

## 変更内容

- `PageSvg.vue`: 読取矩形に `<title>`（項目ラベル / 表 n の r 行 c 列）でツールチップ兼アクセシブル名を付け、`tabindex="0"` + `role="button"` + Enter / Space でクリックと同じ選択を行えるようにする。キーボードフォーカスは選択中と同じ太枠で表示
- `utils/runs.ts`: `OverlayRect` に `label` を追加し、`overlayRectsByPage` で生成する
- `ResultEditor.vue`: 正規化ヒントに `id` を振り入力欄の `aria-describedby` で紐付け。選択中入力欄に `aria-current="true"`。修正済みマークに `role="img"` + `aria-label="修正"`。修正入力欄に `maxlength="2000"`（サーバ側 `CorrectionText` と一致）
- `WorkPanel.vue`: 確認ダイアログに `aria-labelledby` でタイトルを紐付け
- `utils/motion.ts`（新規）: `scrollBehavior()`。`prefers-reduced-motion: reduce` のとき `auto`、それ以外 `smooth`。`ResultEditor` と `DocumentCanvas`（矩形スクロール・ページ移動）の `scrollIntoView` で使用
- `docs/viewer/result-panel.md` / `docs/viewer/display.md` にキーボード操作・アクセシビリティを追記

## 動作確認方法

1. Viewer で成功実行のある文書を開く
2. キャンバスの矩形に Tab でフォーカス → 太枠表示、ホバーでラベルのツールチップ表示
3. Enter / Space で右ペインの該当入力欄がフォーカスされる
4. OS の「視差効果を減らす」を有効にして矩形クリック → 入力欄へのスクロールがアニメーションなしになる
5. 入力欄に 2001 文字以上貼り付け → 2000 文字で打ち切られる

## 備考

- 選択中入力欄の色以外の手掛かりは `aria-current` を採用（Issue の「または」）。視覚上は既存の枠線幅差を維持し、アイコン追加はしていない
- `DocumentCanvas` のページ移動の `scrollIntoView` も同じ reduced-motion 対応を適用した（Issue は `ResultEditor` のみ言及）
