# 概要

原本照合の作業性向上のため、キャンバスにフィットズーム 3 種（幅に合わせる / 高さに合わせる / ページ全体を表示）を導入し、初期表示で書類全体を見せる。

あわせて全状態で表示するフッター（32px）を追加し、右ペイン刷新（#117）に備えてペイン幅を 528px に広げ、2 ペインの高さを Vuetify のレイアウト変数から算出するようにする。API 変更なし。

## 関連Issue

Closes #116

## 変更内容

- `viewer/src/utils/zoom.ts`（新規）: フィット倍率の純粋関数 `fitZoom`。`height` はスクローラの可視高さ（上下 padding 24px×2・ページ枠の下マージン 24px・枠線 1px×2 を除く）に 1 ページが収まる倍率、`page` は `min(100, height)`。切り捨て（epsilon 付き）で数 px のはみ出しを防ぐ。最小 1、計測不能時は 100
- `DocumentCanvas.vue`: ズームモード `width` / `height` / `page` / `custom`。初期表示は `page`。ツールバーに `v-btn-toggle` のフィット 3 ボタン（選択中を強調・`aria-pressed`・ツールチップ）。± は 25 の倍数へスナップ・25〜200%（下限 50% → 25%）で操作後は `custom`（非選択）。`ResizeObserver`（border-box・実寸不変なら無視）でコンテナサイズ変化時に `custom` 以外を再計算（フィットはアニメーションせず即時反映）。複数ページは 1 ページ目の寸法で計算。ツールバーは狭幅で折り返し
- `App.vue`: `v-footer app`（32px）を全状態（ログイン前・認証後・公開閲覧 `/view/{token}`）で表示。左「FactONE Viewer」、右にプレースホルダリンク「プライバシーポリシー」「お問い合わせ」「ライセンス」（`href="#"`）。ログイン画面の高さもレイアウト変数ベースに変更
- `DocumentView.vue`: 右ペイン 380px → 528px。2 ペイン高さを `calc(100dvh - var(--v-layout-top) - var(--v-layout-bottom))` に変更（従来の 64px 固定は app-bar の comfortable 密度 56px と不一致だった）。960px 未満の縦積みフォールバックは維持
- テスト: `fitZoom` 単体（境界・下限ガード・計測不能）、DocumentCanvas（初期 `page`・± で `custom`・スクローラ寸法をモックしたフィット計算・25% 下限）、App（3 状態でのフッター描画とリンク）
- ドキュメント: `docs/viewer/display.md`（ズームモード・画面レイアウト・フッター）、`viewer/README.md`

## 動作確認方法

1. `cd viewer && npm run dev` でログイン画面を開き、下端にフッターが固定され縦スクロールが出ないこと
2. ログイン後に文書を表示し、右ペインが 528px、キャンバスとペインがそれぞれ内部スクロールすること
3. 初期表示で 1 ページ全体が収まり「ページ全体を表示」が選択中であること。「高さに合わせる」で 1 ページの高さがぴったり収まり、「幅に合わせる」で 100% になること。いずれも押下で即時反映（アニメーションなし）
4. ± で 25% 刻みに変化し、フィットの選択が外れること。25% / 200% でボタンが無効になること
5. ウィンドウ幅（または右ペイン幅）を変えると「ページ全体を表示」「高さに合わせる」が追従し、± 後は追従しないこと
6. `/view/{token}` の公開閲覧画面にもフッターが出ること

## 備考

- フッターのリンクはプレースホルダ（文言・遷移先は後続で確定）
- `--v-layout-top` / `--v-layout-bottom` は Vuetify が `v-main` に設定するため、`v-main` の外では 0px にフォールバックする（docs に明記）
- ± は 25 の倍数へスナップする（例: フィット値 85% から拡大 → 100%、縮小 → 75%）
- Viewer の履歴での `corrected` 表示・修正 UI・相互ハイライトは #117 / #118 の範囲
