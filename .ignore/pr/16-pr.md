# 概要

PoC環境のコアAzureリソース（Document Intelligence・Blob Storage・PostgreSQL・Key Vault）をBicepで定義し、デプロイスクリプトを整備する。

## 関連Issue

Closes #15

## 変更内容

- `bicep/main.bicep` — リソースグループスコープのエントリ（モジュール呼出・出力集約）
- `bicep/modules/` — サービス単位のモジュール4本（将来のPrivate Endpoint後付けを考慮した分離）
  - `document-intelligence.bicep` — FormRecognizer S0・カスタムサブドメイン
  - `storage.bicep` — Blob（匿名アクセス無効・TLS1.2強制・`documents` コンテナ）
  - `postgresql.bicep` — Flexible Server B1ms・PostgreSQL 17・Azureサービス許可のファイアウォール規則
  - `keyvault.bicep` — RBAC認可・PostgreSQL管理者パスワードをシークレット格納
- `bicep/main.bicepparam` — パスワードは `readEnvironmentVariable()` で環境変数注入（コミット対象に実値なし）
- `scripts/deploy-infra.sh` — リソースグループ作成＋`az deployment group create` ラッパー
- `docs/develop-guide/deploy.md` 新規作成、README一覧更新
