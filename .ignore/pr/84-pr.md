# 概要

WorkPanelの読み取り結果の項目名をQuery Fieldsキー名から表示ラベル（文書種別設定の`fields`->`label`）に変更。ラベル変更に備え、実行時点のラベルを`idp_runs`にスナップショット保存する。

## 関連Issue

Closes #83

## 変更内容

- `idp_runs`に`field_labels`（JSONB、key→label）カラム追加（マイグレーション `a3d51c7e8b24`）
- 実行成功時に実行時点のラベルを保存（設定変更後も過去実行は当時のラベルを保持）
- idp-runs APIレスポンスに`field_labels`追加（既存run・失敗runはnull）
- OpenAPIエクスポート・TS型再生成
- WorkPanelの項目名を`field_labels`のラベル表示に変更、無い項目はキー名フォールバック
