# 概要

Viewer UIプロダクトレベル化（#74）の最終sub-issue。右ペインの作業パネルをタブ構成（読取結果/実行履歴/閲覧URL）に刷新し、確信度の3段階視覚化と失効確認ダイアログを追加する。

## 関連Issue

Closes #77

## 変更内容

- `WorkPanel.vue` 新設: IDP実行ボタン常置＋タブ切替。`order_*` は読取結果/実行履歴の2タブ、`quote` は+閲覧URLタブ（ADR-0002の表示ゲート踏襲）
- 読取結果を表から行カード形式（項目名＋値＋確信度バー）へ変更。確信度は90%以上=success / 80〜90%=warning / 80%未満=errorの3段階で色分けし、低確信度項目を照合対象として視覚誘導
- `utils/format.ts` 新設: 確信度%表示・3段階分類（閾値0.9/0.8の唯一の定義箇所）・日時フォーマット
- `ViewUrlPanel.vue` 改修: 状態チップ（有効/期限切れ/失効）、失効の確認ダイアログ（取消不可の旨明示）、発行URL再表示不可の注記
- `IdpRunPanel.vue` は責務変化（タブで3機能を束ねる）に伴い `WorkPanel.vue` へ改名・再構成のうえ削除
- テスト: work-panel（旧idp-run-panelの5検証を継承＋確信度色・タブゲート）、失効確認/キャンセル、フォーマッタを追加（47件通過）

## 動作確認方法

1. `cd viewer && npm run dev` でログイン後、注文書の文書IDで起動 → タブ2枚（読取結果・実行履歴）を確認
2. IDP実行 → 結果の行カードと確信度バー（90%↑緑 / 80台琥珀 / 80未満赤）を確認
3. 実行履歴タブで過去行選択 → 読取結果タブへ切替わることを確認
4. 見積の文書IDで起動 → 閲覧URLタブが追加されることを確認。発行→再表示不可注記とコピー、失効→確認ダイアログ（キャンセル/確定）を確認
