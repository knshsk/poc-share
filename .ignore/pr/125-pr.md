# 概要

原本照合で「どの値を書類のどこから読んだか」を即座に突き合わせられるように、キャンバス上の読取領域（キー項目の `field_regions`・グリッドセルの `polygon`）と右ペインの入力欄を相互に連動させる。入力欄にフォーカスすると対応する矩形が強調されて表示範囲へスクロールし、矩形をクリックすると読取結果タブへ切り替わって対応する入力欄がフォーカスされる。API 変更なし。

## 関連Issue

Closes #118

## 変更内容

- 新規 `stores/highlight.ts`: `activeId`（`field:{key}` / `cell:{table}:{row}:{col}`）と、ペイン→キャンバス「矩形を表示範囲へ」／キャンバス→ペイン「入力欄をフォーカス」の連番付き要求。`selectFromPane` / `selectFromCanvas` / `clear`
- `utils/runs.ts`: `polygonToRect`（DI polygon → 外接矩形。インチのまま無変換）、`overlayRectsByPage`（選択中の成功実行からページ番号ごとの矩形。セル = polygon あり全件、キー項目 = 領域あり・`visible=true`・`raw_fields` 非 null。セルを先・キー項目を後）、`fieldId` / `cellId`、`runFieldRegions`
- `PageSvg.vue`: 矩形に `id` / `kind`、`activeId` prop、`rect-click` emit、`data-rect-id`。`field` は破線、`cell` は実線。選択中は primary 32% 塗り + `primary-darken-1` の太枠、ホバーで塗りを強める（semantic color 不使用）
- `DocumentCanvas.vue`: `run` / `fieldDefs` prop から矩形を生成して各ページの `PageSvg` へ。矩形クリックをストアへ、`canvasScroll` 要求で該当矩形を `scrollIntoView({block: 'center'})`
- `WorkPanel.vue`: 選択中の実行を `update:selectedRun` で emit（`DocumentView` が `DocumentCanvas` へ渡す）。`paneFocus` 要求で読取結果タブへ切り替え。履歴選択・IDP実行・確定で選択を解除
- `ResultEditor.vue`: 入力欄フォーカスで `selectFromPane`、選択中の入力欄は primary 10% 背景 + 1px 枠（`target--active`、フォーカスが外れても維持）。`paneFocus` 要求で該当入力欄を `scrollIntoView` + `focus()`（折りたたみ中の区分は開いてから）
- テスト: highlight ストア、`polygonToRect` / `overlayRectsByPage`、PageSvg（ID・種別・選択中クラス・クリック emit）、DocumentCanvas（ページ別矩形・失敗/未選択・クリック→ストア・スクロール要求）、ResultEditor（フォーカス→ストア・active クラス・要求→フォーカス）、WorkPanel（emit・タブ切替・解除・履歴タブ表示中の矩形クリック）、DocumentView（prop 受け渡し）
- ドキュメント: `docs/viewer/display.md`（読取矩形のオーバーレイと相互ハイライト）、`docs/viewer/result-panel.md`（相互ハイライト）、`viewer/README.md`

## 動作確認方法

1. `podman compose up -d postgres` → API 起動、`cd viewer && npm run dev`。文書を表示し IDP実行
2. キャンバスにセル（実線）とキー項目（破線）の矩形が薄く表示され、ホバーで濃くなること
3. 右ペインのキー項目・セルの入力欄をクリックすると、対応する矩形が濃い塗り + 太枠になり表示範囲へスクロールすること。入力欄の背景が薄い primary・枠付きになること
4. 矩形をクリックすると読取結果タブへ切り替わり（実行履歴タブを開いていても）、対応する入力欄がスクロール・フォーカスされること
5. フォーカスを外しても選択が残り、履歴の行選択・IDP実行・確定で選択が消えること
6. 失敗実行の選択中・`visible=false` の項目・領域のない項目（値なし）は矩形が出ないこと。複数ページ文書では各ページに該当矩形が出ること

## 備考

- 結合セル（rowSpan / colSpan）は保持していないため起点セルのみ描画（PoC 制限、spec §10）
- キー項目候補（正規表現一致）は座標を持たないため対象外
- `field_regions` は DI 応答の `boundingRegions[0]` 由来（#113）。座標はインチで、`PageSvg` の viewBox と同一単位のため無変換
- 矩形クリック後は入力欄のフォーカスが `selectFromPane` を再発火し、クリックした矩形が表示範囲の中央に寄る（モックアップと同挙動。意図的に維持）
- 退化した polygon（要素 4 未満）は矩形化しない
