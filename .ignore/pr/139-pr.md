# 概要

見積改訂時に旧版の閲覧用URLをまとめて失効させるため、文書単位の一括失効APIを追加する。

## 関連Issue

Closes #138

## 変更内容

- `POST /api/v1/documents/{document_id}/view-urls/revoke-all` を追加。対象文書の未失効トークンを `revoked=true` にし、`{"status": "revoked", "revoked_count": N}` を返す（対象0件でも200・冪等）
- 文書不存在・他テナントは既存どおり 404 `document-not-found`
- `view_urls.py` で3箇所重複していた文書取得+テナント検査を `documents._get_document_or_404` に統一
- `docs/api/openapi.json` / `viewer/src/api/schema.d.ts` を再生成
- テスト追加: 一括失効後の全トークン404・件数・既失効除外・再実行冪等・未知文書404
