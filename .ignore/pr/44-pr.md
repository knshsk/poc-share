# 概要

シェルスクリプトの実行権限欠落を修正し、今後追加されるスクリプトにも実行権限（755）を強制する pre-commit フックを追加します。

## 関連Issue

Closes #43

## 変更内容

- `scripts/local-stack/init-keycloak-db.sh` の git モードを 100644 → 100755 に修正
- `scripts/check-script-permissions.sh` を追加 — 引数で渡された `*.sh` の git index モードが `100755` でなければ失敗するチェックスクリプト（実ファイルのモードではなく git index を見るため、実行ビットを扱えないファイルシステム上でも機能）
- `.pre-commit-config.yaml` に `script-permissions` フックを追加（`files: \.sh$`）。実行権限のないスクリプトはコミット時に拒否され、修正コマンド（`chmod 755` / `git update-index --chmod=+x`）を提示
- `docs/develop-guide/quality.md` の対象ツール一覧に実行権限チェックを追記

## 備考

644 だったのは `scripts/local-stack/init-keycloak-db.sh` の1本のみで、他4本は元から 100755。git は実行ビットを保存するため、クローン後に全スクリプトが 644 になる場合はクローン先環境側の要因（Windows マウント、`core.fileMode=false` 等）の可能性があります。
