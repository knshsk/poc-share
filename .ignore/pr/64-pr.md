# 概要

Viewer画面に見積PDFの閲覧用URLの発行・管理UIを追加する（業務フロー K3-2〜K3-3 / 要件 VW-01）。

## 関連Issue

Closes #62

## 変更内容

- `ViewUrlPanel.vue` 新設
  - 閲覧URL発行ボタン（`POST /api/documents/{id}/view-urls`）。発行URLは絶対URLで表示しコピー可能（平文トークンは再表示不可のため発行時のみ提示）
  - 発行済みURL一覧（発行日時・有効期限・状態: 有効/失効/期限切れ）
  - 失効操作（`POST /api/view-urls/{id}/revoke`）。失効済み・期限切れ行には失効ボタン非表示
- `DocumentView.vue`
  - 文書メタデータ（`GET /api/documents/{id}`）をページ情報と並行取得し、文書種別を保持
  - 閲覧URLパネルは見積（`quote`）のみ表示。注文書種別では非表示（顧客開示禁止の境界を画面でも担保、ADR-0002。サーバ側403と二重防御）
- コンポーネントテスト追加（発行・コピー・一覧・失効・失効ボタン非表示・発行失敗、DocumentViewの種別ゲート2件）

## 動作確認方法

1. ローカルスタック起動後、見積文書（`document_type=quote`）を登録
2. `/?document_id=<文書ID>` でViewerを開き「表示」
3. 「閲覧URL発行」で発行 → 表示されたURLをコピーし、別ブラウザ（無認証）で `/view/{token}` が閲覧できること
4. 一覧の「失効」実行後、同URLが404になること
5. 注文書文書（`order_project` 等）では閲覧URLパネルが表示されないこと
