### 事象

右ペイン（作業パネル）の幅を変えると、キャンバスの倍率ラベルとページ画像の表示サイズが連動しない。PR #164（#161、右ペイン幅の可変化）で顕在化した。

- 「ページ全体を表示」「高さに合わせる」のとき、ページ画像の表示サイズは変わらないが、倍率ラベルが変わる。右ペインを広げるとラベルの値が大きくなり、狭めると小さくなる
- 「幅に合わせる」と ± ボタン押下後（手動）のとき、ページ画像の表示サイズは変わるが、倍率ラベルが変わらない

原因は、倍率の基準がスクローラの内寸幅になっていること（ズーム値 = スクローラ内寸幅に対するページ幅の比、100% = 幅合わせ。#116 で決定し、`docs/viewer/display.md` に記載）。右ペインの幅を変えると基準そのものが変わるため、ラベルと見た目がずれる。

- ページ全体・高さ合わせ: 高さが制約のとき、ページ幅は可視高さで決まり変わらない。ラベルは「ページ幅 ÷ スクローラ内寸幅」なので変わる
- 幅合わせ: ラベルは常に 100%、ページ幅はスクローラに追従する
- 手動: % を保持するため、ページ幅がスクローラに追従する

ウィンドウ幅の変更でも以前から同じ現象が起きていたが、#164 で右ペインの幅を変えられるようになって目立つようになった。

### 再現手順

1. 文書を開き、キャンバスのツールバーで「ページ全体を表示」を選ぶ
2. キャンバスと右ペインの境界をドラッグ（または境界にフォーカスして ← / →）し、右ペインの幅を変える
3. 倍率ラベルとページ画像の表示サイズを見比べる
4. 「幅に合わせる」「高さに合わせる」、± ボタン押下後についても 2〜3 を繰り返す

### 期待する動作

- 倍率ラベルがページ画像の表示サイズと連動する。表示サイズが変わらなければラベルも変わらず、表示サイズが変わればラベルも変わる

### 実際の動作

1440×900、`order-sample-001`（1 ページ）で右ペインを 528 / 736 / 400px に変えたときの計測。実寸比 = ページ枠の幅 ÷ ページ実寸幅（1 インチ = 96px）。

- ページ全体: ラベル 57 / 76 / 50%、ページ枠の幅 481 / 483 / 486px（実寸比 61% で不変）
- 幅合わせ: ラベル 100 / 100 / 100%、ページ枠の幅 843 / 635 / 971px
- 高さ合わせ: ページ全体と同じ値
- 手動（ページ全体から拡大 1 回）: ラベル 75 / 75 / 75%、ページ枠の幅 632 / 476 / 728px

対応方針: 倍率の基準をページ実寸（100% = 1 インチ 96px）に変える。フィット 3 種は実寸に対する比で計算し、手動の倍率は右ペインの幅を変えても保持する。
