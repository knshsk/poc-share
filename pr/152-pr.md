# 概要

IDP 実行結果の応答を外部連携向けの単一スキーマに再編し、Viewer 向けの付加情報（ラベル・読取領域・セル座標・人手差分）は `verbose=true` で同じスキーマに追加する。テーブルセルに `row_span` / `column_span` を抽出する。

## 関連Issue

Closes #151

## 変更内容

- API: `IdpRunResponse` の `raw_fields` / `normalized_fields` / `confidence` / `field_labels` / `field_regions` を `fields[key].{value, normalized_value, confidence}` に統合。`verbose=true` で `label` / `region` / `cells[].polygon` / `corrections` を追加（4 エンドポイント: 実行・最新・詳細・修正）。非 verbose ではキー自体を省略（`response_model_exclude_unset`）
- DI: `DiTableCell` に `row_span` / `column_span` を追加（既存行は応答で 1 補完）
- Viewer: 生成型に追従し、詳細・実行・修正の呼出に `verbose=true` を付ける。`runs.ts` の手書き型と cast ヘルパを廃止。読取結果タブのキー項目を現在の文書種別設定の順に並べる（JSONB 由来の `fields` はキー順が設定順にならないため。最終レビューで発覚した既存不具合の修正）
- docs: 破壊的変更の記録（`docs/api/README.md`）、`architecture/api.md`・`architecture/viewer.md`、`data-model/idp-runs.md`、`viewer/display.md`・`viewer/result-panel.md`、ADR-0022 新規、OpenAPI・TS 型再生成

## 影響を受けるエンドポイント

応答スキーマ（`IdpRunResponse`）の変更と `verbose` クエリパラメータ（bool、既定 `false`）の追加。すべて `/api/v1` 配下、認証あり。

| メソッド | パス | 変更 |
| --- | --- | --- |
| POST | `/documents/{document_id}/idp-runs` | 応答形状変更 + `verbose` 追加 |
| GET | `/documents/{document_id}/idp-runs/latest` | 応答形状変更 + `verbose` 追加（`run_type` と併用可） |
| GET | `/documents/{document_id}/idp-runs/{run_id}` | 応答形状変更 + `verbose` 追加 |
| POST | `/documents/{document_id}/idp-runs/{run_id}/corrections` | 応答形状変更 + `verbose` 追加（リクエストボディは変更なし） |

応答形状の変更点（上記 4 件共通）:

- `raw_fields` / `normalized_fields` / `confidence` / `field_labels` / `field_regions` を廃止し `fields[key] = {value, normalized_value, confidence}` に統合
- `tables[].cells[]` に `row_span` / `column_span` を追加（常に返す。保存前の行は 1）
- `verbose=true` のときだけ `fields[key].label` / `fields[key].region` / `tables[].cells[].polygon` / `corrections` を返す。既定ではキー自体を省略
- `pattern_matches`、セルの `content`、サマリ項目（`run_id` 〜 `error_info`）は変更なし

変更なし: `GET /documents/{document_id}/idp-runs`（一覧、`IdpRunSummary`）、`GET /documents/{document_id}/idp-runs/{run_id}/raw-response`、閲覧用 URL（`/view/{token}/**`）、その他の API。

1. `podman compose up -d` で起動し、文書を登録して IDP 実行

3. 同 URL に `?verbose=true` を付けると上記キーが現れることを確認
4. Viewer で読取結果タブのラベル・確信度・ハイライト・修正確定が従来どおり動き、キー項目が文書種別設定の順に並ぶことを確認
