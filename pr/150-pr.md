# 概要

閲覧用 URL（`/view/{token}`）で開く `PublicView` を、認証後 Viewer と同じキャンバス（ナビ・ズーム・フィット・ダウンロード）とヘッダ（ロゴのみ）・エラー / ローディング state に寄せる。

## 関連Issue

Closes #149

## 変更内容

- `DocumentCanvas`: `documentId` を任意化し `token` / `downloadLabel` prop を追加。`PageSvg` へ `token` を渡す（既存の token 経路を利用。遅延読込 = `page_view` 記録契機は不変）
- `PublicView`: `v-container` + 素のボタンから `DocumentCanvas` 全幅（右ペイン・読取矩形なし）へ置き換え。取得中はページスケルトン、無効 URL / ダウンロード失敗は `DocumentView` と同じエラー state。文言は現行維持
- `AppHeader`: `minimal` prop 追加（文書 ID バッジ・種別チップ・ユーザーメニュー非表示）。`App.vue` の公開閲覧経路で表示
- テスト: `document-canvas`（token 経路・文言）、`app-header`（minimal）、`App`（公開閲覧ヘッダ）、`public-view`（新規: 成功 / 無効 URL / DL 失敗）
- docs: `docs/architecture/viewer.md`（構成図・公開閲覧節）、`docs/viewer/display.md`（ズーム・レイアウト）

## 動作確認方法

1. ローカルで API + Viewer を起動し、共有可の文書で閲覧 URL を発行する
2. 発行した `/view/{token}` を別ブラウザ（未ログイン）で開く
3. ロゴのみのヘッダ、ページナビ・ズーム・フィット・[ダウンロード] のツールバーが出て、ページ画像が表示領域に入ったときだけ取得されること
4. 失効させた URL を開くと「この閲覧URLは無効です」のエラー state になること
