# 概要

Viewer の UI 是正 第1弾。意図したスタイルが実際には効いていなかった不具合（文字サイズ・フォント・ボタン幅）と、コンポーネント構成を変えずに直せる不整合をまとめて是正する。右ペインの再設計（キー項目の密度・確信度表現・グリッドの表組み化など）は、本 PR 反映後の見た目で再評価してから別 Issue で扱う。

## 関連Issue

Closes #157

## 変更内容

- 全体フォントを Vuetify 4 の CSS 変数 `--v-font-body` で指定する。`.v-application { font-family … !important }` は廃止（`body` 直下へ teleport されるダイアログ・メニュー・ツールチップ・スナックバーに届かず Roboto になっていた）
- タイポグラフィクラスを MD3 名へ置換する（Vuetify 4 に `text-caption` / `text-body-1` / `text-body-2` / `text-h6` は無く、28 箇所が 16px で描画されていた）。確認ダイアログの見出し 2 箇所は `text-title-medium`（16px / 500）。旧名の再混入と `--v-font-body` の定義消失を検出するテストを追加
- 入力欄の `variant` / `density` を `vuetify.ts` の `defaults`（outlined + compact）で統一し、各コンポーネントの重複 props を削除（開始ダイアログ・ヘッダーの文書 ID メニューが filled、読取結果が outlined と混在していた）
- ヘッダー: 文書 ID バッジと種別チップを `prepend` スロット内（ロゴの右隣）へ移動、ロゴの左余白を 16px に
- 右ペイン: 「確定」「破棄」を通常サイズに。「IDP実行」は outlined を基本とし、一覧を取得できていて実行が 1 件も無いときだけ塗りにして「「IDP実行」で読取を開始します」を案内する（取得中・取得失敗時は該当しない）
- 閲覧URL タブ: 状態チップ「失効」→「失効済み」（グレー）、操作ボタン・確認ダイアログの実行ボタン「失効」→「失効させる」
- 等幅フォントを文書 ID・発行 URL・キー項目候補などの識別子に絞り、日時・選択中結果チップ・ページ数・ズーム% は UI フォントに（IBM Plex Sans JP の数字は既定で等幅のため、桁揃えの指定は足していない）
- キャンバスのツールバー: フィット 3 ボタンの `icon` 指定を外して幅を確保（20px → 50px）、ページ送りは複数ページ文書のときだけ表示
- `docs/viewer/display.md` / `docs/viewer/result-panel.md` / `docs/architecture/viewer.md` / `viewer/README.md` を更新

変えていないもの: 初期ズーム（ページ全体を表示）、フッター、IDP実行ボタンの位置、`data-testid`、Mediator のイベントと vm の型。

## 動作確認方法

ローカル環境（postgres / keycloak / API / Viewer）で testuser ログイン後、実行ありの見積文書・6 列表の注文書・実行なしの文書を 1280×720 / 1440×900 / 1920×1080 で表示して確認する。ヘッドレス Chromium での実測結果（1440×900）:

- ラベル（`.field-label`）とフッターの文字サイズ 12px、変更件数 14px（是正前はいずれも 16px）
- ダイアログ・メニュー内の computed font-family が IBM Plex Sans JP（是正前は `Roboto, sans-serif`）、メニュー内の入力欄が outlined
- フィット 3 ボタンの幅 32px 以上（是正前 20px）
- ロゴの左端 x=16、文書 ID バッジがロゴの右隣（是正前は中央 x=651）
- 1 ページ文書でページ送り非表示、実行ありの文書で IDP実行が outlined、実行なしの文書で塗り + 案内文
- 確認ダイアログ（未保存の変更の破棄・閲覧URL の失効）の見出しが 16px / ウェイト 500、実行ボタンの文言が「破棄して続行」「失効させる」
