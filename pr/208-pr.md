# 概要

「文書を登録」タブのPDFのドロップゾーンを、キーボードとスクリーンリーダーで操作できるようにする。PDFを選んだ後の解除ボタンに名前を付け、EnterキーとSpaceキーでも解除できるようにする。解除した後は、フォーカスをドロップゾーンへ移す。透明なファイル入力にはフォーカスが当たらないようにし、未選択のドロップゾーンを、PDFを選ぶボタンとしてスクリーンリーダーに伝える。あわせて、選んだPDFのファイル名の左にファイルのアイコンを表示する。

## 変更内容

- ドロップゾーンの描画（`DocumentRegisterForm.vue`）: `v-file-upload`の既定の描画では、ドロップゾーンの枠と解除ボタンに属性を渡せない。`v-file-upload`に渡した属性は、中のネイティブのファイル入力に付くためである。そこで、枠（`v-file-upload-dropzone`）・ファイル項目（`v-file-upload-item`）・解除ボタンをslotで描くようにした。PDFの受け付け（`filter-by-type`）とドラッグ＆ドロップの処理は、これまでどおり`v-file-upload`が行う。ファイルのアイコンが出るようになったこと以外、見た目は変わらない
- 透明なファイル入力: default slotを使うと、`v-file-upload`はネイティブのファイル入力を`display: none`で描く。Tabキーで止まらなくなり、アクセシビリティツリーからも消える
- 枠: 未選択の枠に`role="button"`を付けた。名前は枠の文言「PDFファイルをドラッグ＆ドロップ、またはクリックして選択」になる。Tabキーで止まり、EnterキーとSpaceキーでファイル選択を開く動作は、Vuetifyの既存の処理である。選択後の枠の中には、解除ボタンと「ファイルを変更」ボタンがある。そのため選択後の枠には`role`を付けず、`tabindex="-1"`でTabキーの対象から外した
- 解除ボタン: アクセシブルな名前「PDFの選択を解除」を付けた。枠はEnterキーとSpaceキーでファイル選択を開き、キーの既定の動作を止める。この処理が解除ボタンで押したキーにも働き、解除されずにファイル選択が開いていた。そこで、解除ボタンのEnterキーとSpaceキーを枠へ伝えないようにした。Escキーは止めないので、解除ボタンにフォーカスがあってもEscキーでダイアログを閉じられる。解除するとボタンが消えるので、フォーカスを枠へ移す
- ファイルのアイコン（`src/plugins/vuetify.ts`）: `v-file-upload-item`は、アイコンの既定値に文字列の`mdi-file-document`を使う。Phosphorのアイコンセットは文字列のアイコン名を解決しないので、アイコンが出ていなかった。エイリアス`$fileDocument`（Phosphorの`PhFileText`）を追加し、`defaults`で`v-file-upload-item`のアイコンの既定値をこのエイリアスにした。文字列のアイコン名を既定値に持つVuetifyの部品は、`v-file-upload-item`だけである
- テスト: `tests/document-register-form.test.ts`で、枠の`role`と`tabindex`（未選択と選択後）、ファイル入力の`display: none`、解除ボタンの名前を確かめる。解除ボタンでEnterキー・Spaceキー・Escキーを押したとき、枠へ伝わるのはEscキーだけであることを確かめる。ファイル選択を開く処理は枠にあるので、枠へ伝わらなければ選択画面は開かない。解除すると選択が消え、フォーカスが枠へ移ることも確かめる。`tests/vuetify-plugin.test.ts`では、ファイル項目のアイコンがSVGで描画されることを確かめる
- ドキュメント: `docs/viewer/display.md`（文書選択ダイアログ）に、ドロップゾーンのキーボードとスクリーンリーダーでの操作を追記した。`docs/develop-guide/viewer.md`（構成メモ）には、アイコンの指定方法を追記した。文字列のアイコン名は描画されないので、エイリアスかPhosphorのコンポーネントを使う

## 動作確認方法

自動テストは、`viewer/`で`npm run test`を実行する。

画面では、URLに`document_id`を付けずにログインする。文書選択ダイアログが「文書を登録」タブで自動で開く。

1. 文書IDの入力欄をクリックし、Tabキーを押す。ドロップゾーンの枠にフォーカスの枠線が出る。もう一度Tabキーを押すと、フォーカスはダイアログ先頭の「文書を登録」タブへ移る。透明なファイル入力には止まらない
2. Shift+Tabキーで枠に戻り、EnterキーかSpaceキーを押す。ファイルを選ぶ画面が開くので、PDFを選ぶ。ファイル名の左にファイルのアイコンが出る
3. 文書IDの入力欄をクリックしてTabキーを押すと、解除ボタン、「ファイルを変更」の順にフォーカスが移る
4. 解除ボタンにフォーカスを当て、EnterキーかSpaceキーを押す。ファイルを選ぶ画面は開かず、選択が解除される。フォーカスは枠に移り、枠線が出る
5. ブラウザの開発者ツールのアクセシビリティツリー（またはスクリーンリーダー）で、ドロップゾーンの中の要素を確かめる。未選択の枠は`button "PDFファイルをドラッグ＆ドロップ、またはクリックして選択"`、選択後の解除ボタンは`button "PDFの選択を解除"`として出る。`Choose File`の`button`は出ない
6. PDFを選んでいない状態で、PDF以外のファイルをドロップゾーンへドラッグ＆ドロップしても、選択されない。PDFをドラッグ＆ドロップすると選択される
7. PDFを選んだ状態で解除ボタンにフォーカスを当て、Escキーを押す。ダイアログが閉じる

## 備考

PDFを選んだ状態でPDF以外のファイルをドラッグ＆ドロップすると、選んでいたPDFの選択が解除される。PDF以外を受け付けなかったことは、画面に表示されない。Vuetifyの`v-file-upload`が、受け付けたファイルだけで選択を置き換えるためである。これは変更前からの挙動で、このPRでは変えていない。
