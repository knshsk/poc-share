# 概要

書類種別の選択肢が1件も無いときに、「文書を登録」タブの選択欄を開くと、「選択できる書類種別がありません」と表示する。これまでは英語の「No data available」が出ていた。あわせてVuetifyのロケールを日本語にする。Vuetifyの部品が出す既定の文言も、画面の他の文言と同じく日本語になる。

## 関連Issue

Closes #202

## 変更内容

- Vuetifyのロケール: `src/plugins/vuetify.ts`の`createVuetify`で、ロケールを日本語（`ja`）にした。これまではロケールを指定しておらず、Vuetifyの既定の文言は英語だった。閉じるボタン付きの`v-alert`や入力欄の`clearable`も、Vuetifyが既定の文言を出す機能である。今後これらを使っても、文言は日本語で出る。これまで画面に出ていたVuetifyの既定の文言は、選択肢が無いときの選択欄の文言だけである。本番ビルドに入るVuetifyのロケールは日本語だけで、他の言語はツリーシェイキングで除かれる
- 選択欄の文言: 書類種別の選択欄（`DocumentRegisterForm.vue`）に、選択肢が無いときの文言「選択できる書類種別がありません」を指定した。Vuetifyの日本語の既定の文言は「データはありません。」で、何が無いのかが分からない。文末には「。」も付くが、画面の他の文言は1文なら「。」で終えていない。選択肢が無いのは、一覧の取得に失敗したときと、テナントに書類種別が登録されていないときである。文言は、どちらの場合にも当てはまるものにした
- テスト: `tests/document-register-form.test.ts`で、選択肢が無いときの文言を書類種別の選択欄に渡していることを確かめる。`tests/vuetify-plugin.test.ts`では、Vuetifyの既定の文言が日本語であることを確かめる。プラグインの翻訳関数で閉じるボタンの名前を取り出し、「閉じる」になることを見る
- ドキュメント: `docs/viewer/display.md`（文書選択ダイアログ）に、選択肢が無いときの文言を追記した。`docs/develop-guide/viewer.md`（構成メモ）には、Vuetifyのロケールを追記した

## 動作確認方法

自動テストは、`viewer/`で`npm run test`を実行する。

1. ブラウザの開発者ツールで、`/api/v1/config/document-types`へのリクエストをブロックする。URLに`document_id`を付けずにログインすると、文書選択ダイアログが「文書を登録」タブで自動で開く
2. 書類種別の選択欄を開く。「選択できる書類種別がありません」と表示される
3. ブロックを外して「再試行」を押す。選択欄を開くと、書類種別が並ぶ

## 備考

ダイアログを開いた直後、書類種別の一覧の応答を待つ間に選択欄を開いても、選択肢が無いので同じ文言が出る。この場合も、これまでは「No data available」が出ていた。応答を待っていることを示す表示は、このPRでは加えていない。
