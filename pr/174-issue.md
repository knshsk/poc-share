### 目的

- 一部の文字が小さく、利用者によっては判読が困難になるおそれがある。編集パネル（読取結果タブ）のラベルは、1920×1080・表示倍率 100% で計算済みの文字サイズが 12px
- 1920×1080 で 11 の画面状態（ログイン、開始ダイアログ、文書画面の読取結果・実行履歴、メニュー、ツールチップ、確認ダイアログ、エラー画面ほか）を計測すると、14px 未満の文字が 27 種あった。12px: キー項目のラベル・状態・読取値、区分の件数、表の見出し、空行のボタン、ヘッダーの文書 ID、フッター、「表示中」、実行履歴の副題、「原本ダウンロード」、ヘッダーの種別チップ、入力欄の浮動ラベル。13px: 表のセル（候補値・発行 URL も 13px）。10px: 「最新」「過去の結果」などのチップ
- 文字のコントラストが WCAG 2.2 の 1.4.3（4.5:1）を満たさない箇所がある: プレースホルダ「（値なし）」1.82:1、実行履歴の選択行の副題 2.35〜3.14:1、入力欄のラベル 3.32:1、開始ダイアログのファイルサイズ 3.32:1、メニューを開いている間のヘッダーの種別チップ 3.61:1、「過去の結果」チップ 4.17:1、エラー通知 4.13:1
- 入力欄の枠（2.01:1）と表の罫線（1.32:1）が、1.4.11（UI 部品の境界 3:1）を満たさない。表のセルは枠の無い入力欄で、罫線がその境界を兼ねている
- WCAG 2.2 には文字サイズの下限を定める達成基準が無い。デジタル庁デザインシステムの基準（本文・UI は 16px が基準、14px は領域的な制約がある場合のみ、14px 未満は原則不許容）に拠り、右ペインに領域の制約がある Viewer では 14px を下限とする

### 変更内容

- 文字の下限を 14px にする: `text-body-small`（12px）18 箇所を `text-body-medium`（14px）に、13px の指定 3 箇所を 14px に、`x-small` のチップを `small` にする。Vuetify の `size="small"` のボタン・チップと入力欄の浮動ラベルは、Vuetify のカスケードレイヤー `vuetify-overrides` で文字を 14px に上書きする（高さは変えない）
- 14px 化に合わせて、キー項目・候補値の状態列を 84px → 96px、表のセルの左右余白を 6px → 4px にする
- テーマの状態色を、色相を変えずに明度だけ下げる（primary `#0F6CBD`→`#0E68B5`、warning `#9A6700`→`#8B5D00`、error `#D13438`→`#C02B2F`、success `#107C10`→`#0F770F`）。白地・12% の淡色地・選択行の灰色地のいずれでも文字 4.5:1 以上にする。Vuetify が補助の文字に掛ける透明度（`medium-emphasis-opacity`）を 0.60 → 0.78 にする
- プレースホルダの透明度（0.38 → 0.85）と入力欄の枠（0.38 → 0.64）を上書きする。ホバー・フォーカス・エラー時の枠と、ラベル付きの未入力の欄でプレースホルダを隠す挙動は Vuetify のまま。表の罫線を入力欄の枠と同じ濃さにする。実行履歴・閲覧URL 一覧の副題は透明度を掛けず secondary 色にする。ヘッダーの文書タイトルボタンは、メニューを開いている間の活性化オーバーレイを出さない
- 右ペインの境界とキャンバスの読取矩形の枠は変えない（1.4.11 の対象外として ADR に記録する）
- 再発防止のテスト（14px 未満のクラス・`size="x-small"`・14px 未満の `font-size`・上書きのレイヤーと import 順・テーマ色のコントラスト比）と、ADR-0024・ドキュメント（`viewer/README.md`・`docs/viewer/result-panel.md`・`docs/viewer/display.md`・`docs/architecture/viewer.md`）

### 対象コンポーネント（複数選択可）

画面（`viewer` 配下）, ドキュメント（`docs` 配下）

### 完了条件

- 1920×1080 の各画面状態で、14px 未満の文字が無い
- 文字のコントラストが 4.5:1 以上（無効状態の部品を除く）
- 入力欄の枠と表の罫線が 3:1 以上
- 右ペイン 528px で、キー項目の状態列がはみ出さず、注文書の 6 列の表のセルが切れない。最小幅 400px でも状態列がはみ出さない
- 入力欄のホバー・フォーカス・エラーの枠の濃さと、ラベル付きの未入力の欄でプレースホルダを隠す挙動が、Vuetify の既定のまま
- テストと pre-commit が通り、ドキュメントが実装と一致している
