# 概要

キャンバスの倍率の基準を、スクローラの内寸幅からページ実寸（100% = 1 インチ 96px）に変える。右ペインやウィンドウの幅を変えても、倍率ラベルとページの表示サイズが連動するようにする。PR #164（右ペイン幅の可変化）で顕在化した不整合の修正。

## 関連Issue

Closes #168

## 変更内容

- `utils/zoom.ts`: 倍率をページ実寸に対する %（100 = 実寸）に変更し、`PX_PER_INCH = 96` を追加
  - `fitZoom`: 幅合わせ = 内寸幅 ÷ 実寸幅、高さ合わせ = 可視高さ ÷ 実寸高さ、ページ全体 = 両者の小さいほう（旧: 幅合わせは常に 100、ページ全体は `min(100, 高さ合わせ)`）。切り捨て・最小 1・計測不能時 100 は維持
- `DocumentCanvas`: ページ枠の幅を `${zoom}%` から「1 ページ目の幅（インチ）× 96 × zoom / 100」px に変更。全ページを 1 ページ目と同じ幅で並べるのは従来どおり。`ResizeObserver` とモードの処理は変えていない（手動の倍率は再計算しないため、幅を変えても表示サイズを保つようになる）
- 右ペインの幅を変えたときの挙動（修正後）:
  - ページ全体・高さ合わせ: 表示サイズもラベルも変わらない（ページ全体は、幅が制約になった時点から両方縮む）
  - 幅合わせ: 表示サイズもラベルも変わる
  - 手動（± 押下後）: 表示サイズもラベルも変わらない
- 公開閲覧（`/view/{token}`）も同じ `DocumentCanvas` のため、同じく実寸基準になる
- テスト: `zoom.test.ts` を実寸基準に書き換え（浮動小数誤差のケースを含む）。`document-canvas.test.ts` に、4 モードでスクローラの幅が変わったときのラベルとページ枠の幅（px）の検証と、複数ページの幅の検証を追加。`ResizeObserver` の stub を `document-view.test.ts` から `fixtures.ts`（`stubResizeObserver`）へ移して共用
- ドキュメント: `docs/viewer/display.md`「キャンバスのズーム」

変えていないもの: ± の範囲（25〜200%）と刻み（25）、初期モード（ページ全体）、`ResizeObserver` の観測方法、Mediator・vm の型。

## 動作確認方法

ローカル環境で testuser ログイン後、文書を開き、各モードでキャンバスと右ペインの境界を操作して、倍率ラベルとページの表示サイズを見比べる。

ヘッドレス Chromium での計測（1440×900、`order-sample-001`、右ペイン 528 / 736 / 400px。実寸比 = ページ枠の幅 ÷ ページ実寸幅）:

- 修正前
  - ページ全体・高さ合わせ: ラベル 57 / 76 / 50%、ページ枠 481 / 483 / 486px（実寸比 61%）
  - 幅合わせ: ラベル 100 / 100 / 100%、ページ枠 843 / 635 / 971px
  - 手動（ページ全体から拡大 1 回）: ラベル 75 / 75 / 75%、ページ枠 632 / 476 / 728px
- 修正後（いずれもラベル = 実寸比）
  - ページ全体・高さ合わせ: 61 / 61 / 61%、ページ枠 484px で不変
  - 幅合わせ: 106 / 79 / 122%、ページ枠 841 / 627 / 968px
  - 手動: 75 / 75 / 75%、ページ枠 595px で不変

## 備考

- 倍率の数値の見え方が変わる。幅合わせは 100% と出なくなり、画面の幅に応じた値になる（例: 1920px 幅・既定の右ペイン・A4 で約 166%）
- 広い画面では ± の最大倍率が実質下がる（1920px 幅: 旧 200% ≒ 実寸の約 330% → 実寸の 200%）。ページ画像は 150dpi のため、画像の等倍（実寸の 156%）は範囲内
- 幅合わせ・高さ合わせの値が 200% を超えるとき（例: 2560px 幅の画面での幅合わせ）、「+」は無効で、「−」1 回で 200% になる（225% ではない）。± を 25〜200% に制限する既存の仕様どおりで、旧実装でも高さ合わせで同じ挙動があった
