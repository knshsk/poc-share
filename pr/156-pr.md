# 概要

Viewer の全コンポーネントを `Root.vue` を頂点とする階層に置き、各コンポーネントを `vm` prop だけを受ける Passive View にし、操作を `useBubble()` の鎖（provide/inject の Chain of Responsibility）で上へ伝えて、`createMediator()` のステートマシンが裁定する構造に作り替える。挙動は原則不変（下記の裁定差のみ）。Pinia は撤去する。

## 関連Issue

Closes #155

## 変更内容

- `src/mediator/`（bubble / events / model / vm / machine / handlers）と `src/auth/oidc.ts` を新設し、API 呼出・状態・レース裁定・未保存ガード・相互ハイライトを Mediator に集約
- `App.vue` → `Root.vue`。全コンポーネントを `vm` prop + `useBubble()` に書き換え（`defineEmits` 全廃）。`views/LoginView.vue` を追加
- 4 つの Pinia ストアと `pinia` 依存を削除
- テストを Mediator 単体（`tests/mediator-*.test.ts`）と View 単体（vm → DOM、DOM → bubble）に再編。`tests/fixtures.ts` を新設（26 ファイル / 219 件）
- `docs/architecture/viewer.md` / `docs/viewer/display.md` / `docs/viewer/result-panel.md` / `docs/architecture/auth.md` / `docs/develop-guide/viewer.md` / `viewer/README.md` を更新、ADR-0023 を追加

裁定による挙動差（ADR-0023 影響節）:
- `executing` / `saving` 中の履歴選択・文書切替・再実行は無視する
- `loadingDocument` / `registering` 中のヘッダからの文書切替は無視する
- `beforeunload` の警告は `Root` が常時登録し `vm.dirty` で判定する
- ヘッダで表示中と同じ文書 ID を再入力すると再取得する
- `/view/` でトークンが空なら公開画面ではなくログイン画面に倒す（旧 `App.vue` と同じ）
