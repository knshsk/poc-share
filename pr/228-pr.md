# 概要

読取結果の確信度による注意表示を、「要確認」と「要注意」の2段階にする。確信度50%以上80%未満を要確認、50%未満を要注意とし、要注意の値は入力欄（明細ではセル）を赤枠で強調する。確信度80%以上の値には何も表示しない。閾値は全エンジン共通の定数とし、その判断をADR-0031に記録した。

Closes #227

## 変更内容

- 判定（`viewer/src/utils/fieldStatus.ts`）: 閾値`LOW_CONFIDENCE`を、`WARNING_CONFIDENCE = 0.8`と`CAUTION_CONFIDENCE = 0.5`の2つに改めた。状態の`kind`は`low`をやめて`warning` / `caution`に分け、文言を「要確認（確信度 62%）」「要注意（確信度 42%）」にした。確信度80%以上の値は文言を空にし、これまで出していた灰色の「92%」も出さない。状態の優先順位（未保存 > 修正済 > 未読取 > 確信度）は変えていない
- 状態表示（`FieldStatusBadge.vue`）: 要確認はwarning色の三角（`PhWarning`）、要注意はerror色の丸（`PhWarningCircle`）のアイコンで示す。キー項目の状態列ではアイコン（16px）だけを出し、文言は`title`（ツールチップ）と読み上げ用の見えないテキスト（`d-sr-only`）に置く。明細の詳細欄では、アイコンに文言を添える（`labelled`）
- キー項目（`KeyFieldList.vue`）: 状態列を96pxから64pxに縮めた。要注意の入力欄は、枠をerror色の2pxにする。Vuetifyはホバー・フォーカスのときに枠の太さと濃さを書き換えるため、同じ`.v-field__outline`の変数を上書きしている。選択中は、赤の枠の内側に主色の2pxの枠を重ねる。値を入力して未保存になったら、赤枠を外す
- 明細（`ItemTable.vue`）: セルの左端のアイコンを段階ごとに出し分け、文言をセルの`title`に置いた。要注意のセルには内側にerror色の2pxの枠を付け、選択中・フォーカス中は主色の枠を重ねる。未保存になると赤枠は外れるが、アイコンと`title`は残す。入力中に文字が左へずれないようにするためである。強制配色ではbox-shadowが描かれないため、要注意のセルには透明のoutlineを置き、強制配色のときだけ枠を見せる。フォーカス中の入力欄のoutlineは内側に寄せ、要注意の枠と重ねない
- 候補値（`ResultEditor.vue`）: 行の列構成はキー項目と同じなので、状態ぶんの空きを64pxにそろえた
- テスト: `tests/field-status.test.ts`では、境界値（0.8・0.799・0.5・0.499・0）と優先順位を確かめる。`tests/key-field-list.test.ts`と`tests/item-table.test.ts`では、アイコン・`title`・読み上げの文言を確かめる。あわせて、赤枠のクラスが未保存で外れ、元の値に戻すと付き直すこと、修正済みの値には付かないことも確かめる。`tests/result-editor.test.ts`では、候補値の行とキー項目の行の列幅が同じことを確かめる
- ドキュメント: ADR-0031を起票し、ADR-0029に追記した。`docs/viewer/result-panel.md`・`docs/data-model/idp-runs.md`・`docs/architecture/viewer.md`を更新した

## 動作確認方法

自動テストは、`viewer/`で`npm run test`を実行する。

画面では、Chromeの開発者ツールのローカルオーバーライドで、実行結果の詳細の応答の確信度を書き換えて確かめる。

1. 実行結果のある文書を開く。Networkパネルで`idp-runs/{run_id}?verbose=true`の要求を右クリックし、「Override content」を選ぶ
2. 応答の`fields`で、キー項目の1つの`confidence`を`0.62`に、別の1つを`0.42`にする。明細のある文書では、明細の値の1つの`confidence`も`0.42`にする。保存して再読込する
3. 0.62の項目では、状態列に黄の三角アイコンだけが出る。マウスを載せると「要確認（確信度 62%）」が出る。0.42の項目では赤の丸アイコンが出て、入力欄の枠が赤になる。確信度80%以上の項目には何も出ない
4. 0.42の入力欄をクリックすると、赤の枠の内側に青の枠が重なる。1文字入力すると状態が「未保存」になり、赤枠が外れる。その文字を消して元の値に戻すと、赤枠が戻る
5. 明細の0.42のセルでも、赤枠と選択中の二重枠が付き、入力すると赤枠が外れることを確かめる。入力中もアイコンは残る。セルを選ぶと、表の下の詳細欄に「要注意（確信度 42%）」が出る

## 備考

閾値はエンジン共通にしたため、`azure-cu`では正解の約半数に要確認が付く。評価の数値と、閾値を見直す条件はADR-0031に書いた。ツールチップはマウスでしか出ないので、キーボードで操作する場合は文言が見えない。この場合も、赤枠とアイコンの形で段階を区別できる。
