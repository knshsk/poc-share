# 概要

ページ画像の取得に失敗したページに「再試行」ボタンを置き、Viewerを再読込せずにそのページの画像を取り直せるようにする。連打しても要求は重ならない。失敗がすぐ返る場合も、要求は1ページにつき1秒に1回までになる。

## 関連Issue

Closes #210

## 変更内容

- 再試行ボタン（`PageSvg.vue`）: 失敗の表示（警告アイコンと「ページを表示できませんでした」）の下に「再試行」ボタンを置いた。押すと`retryPageImage{page}`をbubbleし、Mediator（`handlers/public.ts`）がそのページの画像だけを取り直す。認証済みの表示と公開閲覧のどちらでも動く。応答を待つ間は失敗の表示を残し、ボタンを読込中の表示にする。`disabled`にしないのは、押した直後にフォーカスが外れるためである
- 連打の対策: Mediatorは、取得中のページへの再要求を捨てる。再試行が失敗したときは、押してから1秒経つまで失敗を反映しない。その間もページは取得中のままなので、押下は捨てられる。取得できたときは、1秒を待たずに表示する
- 読込中のボタンの押下: 失敗の表示は、下の読取矩形を押せるように`pointer-events: none`にしてある。Vuetifyは読込中のボタンも`pointer-events: none`にするため、そのままでは連打の押下がボタンの下の読取矩形に届き、矩形を選択してしまう。そこで、ボタンは読込中も押下を受けるようにした。重ねた押下はMediatorが捨てる
- フォーカス: 取得できると、押したボタンが失敗の表示ごと消える。このときフォーカスがbodyに落ちていれば、そのページの枠へ移す。枠は`tabindex="-1"`と`role="group"`を持ち、名前は「Nページ目」である。フォーカスを移してもスクロール位置は変えない。応答を待つ間にほかの要素へ移っていれば、フォーカスは動かさない。また、失敗の表示を紙面の`svg`より前に置き、Tabキーで読取矩形より先に「再試行」ボタンへ届くようにした
- 取得中のページの扱い: Mediator内部の`imageInflight`（Set）を`imageLoading`（Record）に変え、`vm.canvas.imageLoading`として`PageSvg`へ渡す。ボタンの読込中の表示と紙面のスピナーは、どちらもこの値で判定する。`PageSvg`が自前で持っていた`requested`はやめた
- テスト: `tests/mediator-document.test.ts`では、失敗したページの取り直しを確かめる。応答待ちの間と失敗の保持中に押しても要求が増えないこと、成功は待たずに反映することも確かめる。`tests/mediator-public.test.ts`では公開閲覧の再試行を確かめる。`tests/page-svg.test.ts`では、ボタンの表示とbubble、読込中の表示、Tabキーの順、成功後のフォーカスを確かめる。`tests/document-canvas.test.ts`では`imageLoading`の受け渡しを確かめる
- ドキュメント: `docs/viewer/display.md`（読込中の表示）、`docs/architecture/viewer.md`（文書表示の流れ）、`docs/architecture/view-url.md`（公開閲覧の失敗の表示）を更新した

## 動作確認方法

自動テストは、`viewer/`で`npm run test`を実行する。

画面では、Chromeの開発者ツールのNetworkパネルで、ページ画像の要求をブロックして失敗を再現する（Request blockingに`*/pages/1/image`を追加する）。

1. ブロックを有効にした状態で文書を開く。1ページ目に、警告アイコンと「ページを表示できませんでした」、「再試行」ボタンが出る
2. 「再試行」ボタンを素早く何度も押す。押し始めてから1秒の間はボタンが読込中の表示になり、Networkパネルに出る画像の要求は1件だけである。読取矩形のある文書でも、ボタンの下の矩形は選択されない
3. 「原本ダウンロード」ボタンにフォーカスを当てて、Tabキーを押す。フォーカスは「再試行」ボタンへ移る。Enterキーを続けて押しても、要求は1秒に1件までになる。失敗した後も、フォーカスはボタンに残る
4. ブロックを解除し、「再試行」ボタンでEnterキーを押す。待たずにページが表示され、フォーカスはページの枠へ移る
5. 閲覧URL（`/view/{token}`）でも、同じ手順で再試行できる

## 備考

認証済みの表示では、ログインから5分（アクセストークンの寿命）を過ぎると、ページ画像の取得が401で失敗する。この失敗は再試行しても回復しない。原因が別なので、#209 で扱う。
