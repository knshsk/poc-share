# 概要

Power Automate（PA）から文書登録 API へ PDF を送ると、日本語のファイル名が `?` に化けて保存される（`ABCあいう.pdf` → `ABC???.pdf`）。原本ファイル名を本文のテキストフィールド `original_filename` でも受けられるようにして解消する。PA の HTTP アクションは multipart のパートヘッダ（`filename`）の非 ASCII 文字を `?` に置き換えて送るが、パートの本文は UTF-8 のまま届く（PA の実機で確認した）。

## 関連Issue

Closes #178

## 変更内容

- `POST /api/v1/documents` に任意のテキストフィールド `original_filename` を追加した。`file` パートの `filename` より優先して原本ファイル名に使う
- 正規化は `filename` と同じ（パス区切り `/` `\` より後ろを取り、前後の空白を除き、255 文字で切り詰める）。正規化した結果が空（空・空白のみ・パス区切りで終わる値など）なら、従来どおり `filename` を使う。受け取る値には長さの上限を設けない（フルパスを渡すと、basename を取る前に 255 文字を超えうるため）
- 冪等な再送（同一内容で 200）では、既存の原本ファイル名を上書きしない（変更なし）
- OpenAPI（`docs/api/openapi.json`）と TS 型（`viewer/src/api/schema.d.ts`）を再生成した。フィールドの説明に、PA のパートヘッダの置き換えと使い方を書いた。Viewer の画面登録は `original_filename` を送らない（ブラウザは `filename` を UTF-8 のまま送れる）
- テスト（`api/tests/test_documents_api.py`）
  - `filename` が `ABC???.pdf`、`original_filename` が `ABCあいう.pdf` のとき、応答の `original_filename` と原本ダウンロードの保存名が `ABCあいう.pdf` になる
  - `original_filename` が空・空白のみなら `filename` を使う
  - パス付きの `original_filename` は basename だけを保存する
- ドキュメント
  - ADR-0025（`docs/adr/0025-non-ascii-values-in-body.md`）: 外部連携から受ける値のうち非 ASCII を含みうるものは、ヘッダ（multipart のパートヘッダを含む）ではなく本文で受ける。却下した代替案（`filename` の percent-decode、`filename*`、multipart の本文全体の base64）と理由を記録した
  - `docs/data-model/documents.md`（`original_filename` 列の取得元）、`docs/architecture/api.md`（文書登録の流れ）

## 類似事象調査

PA がリクエストヘッダに非 ASCII を載せられない前提で、PA が API を呼ぶときのヘッダを調べた。自由な文字列が入るのは multipart の `filename` だけだった。`Authorization` はアクセストークン、パート名（`name`）は固定の ASCII で、`document_id`・`document_type` はパートの本文で送る。API はカスタムヘッダを受け付けていない。調査中に見つけた原本ダウンロードの不具合は #179 で直す。

- `cd api && uv run pytest tests/test_documents_api.py`
- PA から確かめる場合: HTTP アクションの `$multipart` にテキストのパート（`Content-Disposition` は `form-data; name="original_filename"`、本文はファイル名）を足して登録する。応答の `original_filename` と、Viewer のヘッダーの文書タイトル・原本ダウンロードの保存名が日本語のまま出ることを確かめる

## 備考

- PA のフローは `original_filename` のパートを足すだけでよい。`file` パートの `filename` は省けない（無いとファイルとして扱われず 422 になる）ため、化けた値のまま送ってよい
- 任意パラメータの追加なので、版は v1 のまま（`docs/api/README.md` のバージョニング規則）
