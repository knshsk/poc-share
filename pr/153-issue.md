### 目的

文書ID未指定時の開始ダイアログは「閲覧 / 新規登録」の選択画面を経由する2段構成で、登録フォームの PDF 指定も `v-file-input` のみでドラッグ＆ドロップができない。1画面で用途を切り替えられるタブ構成にし、登録操作を直感的にする。

### 変更内容

- 開始ダイアログを2タブ構成（「文書を登録」「文書IDで参照」）にする。初期表示は「文書を登録」タブ。選択画面と「戻る」ボタンは廃止
- タブアイコンは phosphor-icons の `file-arrow-up` / `file-magnifying-glass`
- 「文書を登録」タブ: 書類種別 → 文書ID → PDF ドロップゾーン（`file-dashed` アイコン、ドラッグ＆ドロップまたはクリックで OS のファイル選択）→ 登録ボタンの順。Vuetify `v-file-upload` を利用し、選択後はゾーン内にファイル名・サイズ・変更・解除を表示する。非 PDF はドロップ時に拒否する
- 「文書IDで参照」タブ: 文書ID入力と参照ボタン。タブ切替時に入力欄へフォーカス
- 登録／参照ボタンは必須入力が揃うまで無効化する
- 両タブの高さを揃え、タブ切替でダイアログ高さが変わらないようにする
